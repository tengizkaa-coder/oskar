# Инструкция следующему агенту: АлкоМосква

## Назначение

Это автономный **статический** вариант сайта, подготовленный для переноса в репозиторий `tengizkaa-coder/oscar-create`. Не путайте его с оригинальным Next.js-проектом из того же репозитория: это другая, упрощённая версия дизайна. Исходник Next.js и его серверные функции архив НЕ заменяет по функционалу. Перед заменой содержимого репозитория сохраните исходный проект в резервную копию; не удаляйте `.git` и не загружайте секреты.

## Что здесь работает

- Главная `index.html`, каталог `catalog/index.html`, 67 фотографий товаров, категории и поиск по названиям.
- Корзина работает на клиенте через localStorage. Количество можно менять, позиции удаляются уменьшением до нуля. Оформление открывает `tel:+74950959599`. Состав заказа **не отправляется** — покупатель должен продиктовать его по телефону. Нет цен, онлайн-оплаты или формы заказа.
- Отдельный просмотр `test/` и `test/catalog/` доступен с любого устройства. Тестовые HTML имеют `noindex,nofollow`. Исходный 18+ стартовый попап убран; предупреждение в футере оставлено.
- Основные страницы открываются мобильным при переходе с Google/Яндекс и поисковым роботам по user-agent. Внутренний переход с сайта в каталог разрешён мобильным по same-origin referrer. Desktop и прямые ссылки блокируются белым экраном. Правила в `gate.js`, и явной записи-разрешения в localStorage/sessionStorage нет.

## Важные ограничения

1. Проверки user-agent/referrer на клиенте **не являются защитой** и не гарантируют, что робот настоящий: их можно подделать, а у реального пользователя referrer может отсутствовать. Сохраните эти ограничения по указанию владельца, если он явно не попросит иначе. Предупредите, что ограничения могут мешать поисковой видимости и пользователям.
2. Реальная поисковая выдача и переход из Google/Yandex после публикации не проверены; локально проверены эмуляция реферера, десктопная блокировка, `/test/`, переход в каталог и корзина. Индексация не гарантируется.
3. Это **не подключённый к Supabase** сайт. Не меняйте существующий Supabase-проект или действующего Telegram-бота без явной необходимости; существующая схема `oscar_site` создана для предыдущего Next.js-проекта и здесь не используется.
4. Каталог собран из загруженных изображений, без оригинальной базы товаров. Некоторые подписи корзины взяты из имён файлов и могут быть неточными. Уточните ассортимент, подписи, фактические условия доставки и тексты до коммерческого запуска. Фразы о времени доставки в исходном шаблоне не подтверждены.
5. Не копируйте опубликованный ранее `.env` из старого проекта. Если какие-то из находившихся в нём токенов и паролей всё ещё действуют, их следует перевыпустить: публичная история хранит предыдущие версии.

## Развёртывание

Содержимое ZIP нужно распаковать **в корень** нового репозитория; `index.html` лежит рядом с `gate.js`, `styles.css`, `catalog/`, `images/`, `test/`. Файлы связаны относительными путями и рассчитаны на публикацию как GitHub Pages из `main` и `/(root)`, включая project site под `/oscar-create/`. Для локальной проверки можно открыть каталог через любой статический HTTP-сервер (не обязательно Ubuntu).

После настройки Pages проверьте статус публикации, `/test/`, переход в тестовый каталог, изображения, поиск, корзину и `tel:`. После приобретения домена настройте домен/DNS и HTTPS, затем создайте sitemap с правильными абсолютными URL и отправьте в Search Console, не включая тестовые страницы. `robots.txt` сейчас содержит только разрешение обхода; домен и sitemap специально не выдуманы. Основные страницы допускают индексирование; поисковики сами решают, показывать ли сайт.

## Файлы

- `index.html`, `styles.css`, `home.js` — главная и меню.
- `gate.js` — клиентские правила доступа на основные страницы.
- `catalog/index.html`, `cart-ui-v3.css`, `cart-ui-v3.js`, `products.json` — каталог и корзина. Карточки формируются непосредственно в HTML; JSON является справочным списком, не динамической базой.
- `images/` — оптимизированные изображения.
- `test/index.html`, `test/catalog/index.html` — общедоступные варианты для ручной проверки с ссылками на те же ресурсы.
- `README.md` — инструкция владельцу по переносу.
