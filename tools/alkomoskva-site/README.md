# АлкоМосква — готовый статический сайт

В архив входят `index.html`, `gate.js`, `styles.css`, `home.js`, каталог `catalog`, изображения `images`, тестовый просмотр `test` и `robots.txt`. Для работы не нужны Ubuntu, Next.js или Supabase. Корзина хранится в браузере; кнопка оформления открывает звонок +7 (495) 095-95-99, содержимое корзины оператору автоматически не передаётся.

## Установка в отдельный репозиторий

1. Сделайте резервную копию исходного проекта `oscar-create`: в нём находится другая Next.js-версия. Этот статический комплект не поддерживает её сервер, базу, админку и Telegram-бота. Не копируйте `.env` и секреты в публичный репозиторий.
2. Откройте в GitHub Desktop клон `oscar-create`, убедитесь, что в нём нет несохранённых изменений. Скопируйте старые файлы сайта в резервную папку вне репозитория. Удалите старые файлы сайта из рабочей папки, НЕ трогая скрытую папку `.git`.
3. Распакуйте содержимое архива в корень клона: `index.html` должен лежать непосредственно внутри папки `oscar-create`, рядом с `styles.css` и `catalog`. В Desktop проверьте изменения, затем сделайте Commit и Push origin.
4. В GitHub → Settings → Pages выберите Deploy from a branch → `main` → `/(root)` → Save. Дождитесь завершения публикации. На GitHub Pages ссылка будет указана в Settings → Pages. Без отдельного домена адрес имеет вид `https://ИМЯ.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.
5. Для проверки с компьютера и прямой ссылки откройте путь `test/` после адреса сайта, например `https://ИМЯ.github.io/ИМЯ-РЕПОЗИТОРИЯ/test/`. Поисковикам тестовые страницы запрещены к индексации. Никаких паролей не отправляйте в чат.
6. Когда купите домен, настройте его в Pages и DNS. Затем обновите sitemap и Search Console под реальный домен; сейчас домен не указан и sitemap не выдуман.

## Ограничения

Основные страницы открываются телефонам с перехода из Google или Яндекса; на каталог можно перейти с самого сайта на телефоне. Поисковые роботы допускаются по user-agent; остальные видят белый экран. Путь `test/` и его каталог открыты для просмотра с любого устройства без установки постоянного обхода. Ограничения на JavaScript не являются защитой: user-agent и referrer можно подделать, а реальный посетитель может не попасть при отсутствии referrer. Выдача и индексация поисковиками не гарантированы. Проверьте тексты, ассортимент и условия перед публикацией.
