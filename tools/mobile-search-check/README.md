# Проверка мобильного перехода из поиска

Сценарий выполняет **один** поисковый запрос в Google с эмуляцией телефона Pixel 7, ищет обычный результат для `alcohub-msk.com`, переходит на него и нажимает до трёх ссылок категорий на странице. Не нажимает кнопки звонка, не отправляет формы и не совершает заказ. Запускается только с явным флагом `--live`.

Внимание: автоматические запросы к Google без разрешения нарушают его условия; искусственные клики могут игнорироваться и не гарантируют рост позиций. Работа скрипта может привести к ограничениям со стороны Google. При CAPTCHA или запросе согласия скрипт останавливается — решения или обхода в нём нет. Разметка Google может измениться; наличие сайта в поисковом индексе не гарантирует его нахождения по конкретному запросу на первой странице. Некоторые посетители могут не попасть на сайт из-за действующего ограничения на referrer.

## Установка на своём сервере

Нужны Node.js 20+ и зависимости Chromium для Linux. В этой папке:

```sh
npm ci
npx playwright install --with-deps chromium
npm test
```

Проверка с реальным Google (нажмите один раз, задание из одного запроса):

```sh
npm start -- --live --query 'доставка алкоголя москва'
```

Без `--live` реальный поиск не выполняется. Проверка прекращается, если целевой сайт не найден на первой странице, при CAPTCHA, незавершённом согласии или отклонённом переходе. Скрипт не пытается обойти эти ограничения и не использует сторонние прокси. Формат поисковой страницы может измениться: проверяйте его перед реальным запуском; селекторы не гарантируют безошибочного распознавания рекламных блоков.

Результаты пишутся только в консоль. Для оценки реальных запросов используйте Search Console; вызовы этого инструмента могут исказить статистику посетителей и не являются реальными заказами.
